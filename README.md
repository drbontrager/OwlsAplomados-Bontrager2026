# OwlsAplomados-Bontrager2026

This repository contains the code and data for the analysis in Bontrager, D.R., McCabe, J.D., Juergens, P.W., Mutch, B.D., Isaak, C., Caughlin, T.T, & Cruz, J. (2026). Assessing impacts of two generalist owl species on endangered Aplomado Falcons in encroached grasslands. Ecology and Evolution. doi: TBD.

Files are as follows:

1. MultimethodOccupancyCode.txt - used to estimate Great Horned Owl and Barn Owl occupancy using NIMBLE.
2. OwlData.Rda - data/workspace for MultmethodOccupancyCode
3. HierarchicalReproductionModelCode.txt - used to estimate Aplomado Falcon nest occupancy and nestling survival using JAGS.
4. AplomadoData.Rda - data/workspace for HierarchicalReproductionModelCode

Detailed model descriptions and formulas are describe in the manuscript. Raw data are in ScholarWorks repository: (doi)
